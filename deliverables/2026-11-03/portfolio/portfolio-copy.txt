DEPTH AI — 소스 기반 모듈 탐색과 AI 변경 제안을 결합한 데스크톱 프로토타입

짧은 소개
AI가 만든 프로젝트를 사용자가 이해하고 수정할 수 있도록, 코드 선언과 의존 관계를 모듈 그래프로 시각화하는 Windows 데스크톱 프로토타입을 개발했다. 소스 근거를 가진 탐색, 조작 가능한 도킹 패널, Meta 기반 설명·변경안, 검토·검증·되돌리기 흐름을 구현했다. 실제 런타임과 화면 요소를 연결하는 실험을 진행하며, 시각적 시안과 동작하는 제품 사이의 검증 간극을 확인했다.

핵심 작업
• Electron과 독립 .NET 서비스 사이의 IPC 및 신뢰 경계 구성
• Roslyn / TypeScript compiler / Dart analyzer를 사용한 선언·참조·소스 위치 추출
• 역할별 노드, 전체 의존 구성, 소스 근거, 이동·도킹·탭·크기 조절 UI
• Meta 설명과 코드 변경안을 현재 소스 ID·revision·hash에 연결하는 검증 흐름
• 지원되는 AST literal의 값 편집, 일괄 적용과 undo
• 웹 런타임 및 Unity / Flutter / WinForms 개발 어댑터 연결 실험

검증 범위
첨부한 제품 화면 6장은 2026-11-02의 Electron 0.6.1 실제 캡처다. 화면 왼쪽 Checkout은 선언형 예제 프리뷰이며, 임의 프로젝트 실행 성공을 증명하지 않는다. 별도 WinForms 이미지 2장은 실제 대상 앱 컨트롤 렌더링으로, 버튼 세 번 입력과 소스 추적을 확인한 테스트의 전후 결과다. 최신 0.9.1의 전체 EXE 화면은 새로 검수하지 못했다.

미완료 항목
임의 프로젝트의 모든 UI 요소 자동 소스 연결, Unity / Flutter 전체 실행 검수, 실제 3D 메시 생성, 최종 제품 안정성·시각 검수는 완료하지 못했다. 내부 테스트 통과 수를 실제 사용자 환경의 전체 기능 성공으로 환산하지 않는다.

회고와 다음 방향
범용 IDE·생성·실행·리팩터링을 동시에 해결하려던 범위가 과도했다. 다음 프로젝트는 읽기 전용 폴더 이해에 집중한다. CLI로 만든 프로젝트의 실제 소스 관계를 투명 데스크톱 패널에서 보여주고, 연결선마다 근거를 확인할 수 있게 한다. 소스에서 확인한 사실과 AI 설명을 명확히 구분한다.

기술
Electron · JavaScript · .NET 8 / C# · Roslyn · TypeScript compiler · Dart analyzer · Meta Model API

작업 방식
사용자 주도의 제품 요구·설계·검수와 Codex를 활용한 AI 보조 개발. 모델 설정은 muse-spark-1.3 / muse-image-1.0이며, 인덱싱·직접 값 편집·프로세스 연결은 모델 추론이 아닌 프로그램 로직으로 처리했다.
