PC에서 실행되는 공간뷰

사용자가 좋아한 MR 방향을 PC의 실제 Unity 공간뷰로 연결했습니다. 원근 카메라·개별 몸체·source ID·선택 이동·방향 참조선이 동작합니다. 이 캡처는 imagegen 이미지가 아닙니다.

빈 공간을 누른 채 드래그해 시점을 움직이고, 마우스를 놓으면 멈춥니다. Overview는 선택한 몸체를 복귀시킵니다. Workbench는 기존 정면 편집 화면입니다. 실행 검증 기록

실제 PC 구현 · 2번과 3번 조합

2번의 하이어라키·프리뷰·기능 구성·하단 CLI/라이브러리 배치에 3번의 밝은 모듈 몸체와 설계 근거를 결합한 현재 수정본입니다. 아래 캡처는 격리된 소스 예제에서 25% 적용 후 재분석한 실제 앱입니다. 시각적 최종 승인을 받은 화면은 아닙니다.

PC 공간뷰는 실제 3D 몸체와 렌더 텍스처, 정면 조작면을 사용합니다. Workbench는 UI Toolkit의 절차적 몸체·음영 표현입니다. MR 레퍼런스의 실물 공간·광학 표현을 구현 완료한 것은 아닙니다. 검증 기록: validation.md · 실제 소스 변경 결과
