01
라이트 모드
라이트 · 선택 전 공간 탐색
왼쪽 프리뷰는 정면으로 고정하고, 오른쪽에서 프로젝트의 모듈 공간을 둘러봅니다. 뒤편 파편들은 실제 모듈과 에셋을 나타내는 설계입니다.


02
라이트 모드
라이트 · 선택하면 오른쪽 정면으로, 전체는 아래로
프리뷰의 Apply를 선택한 상태입니다. 기능 구성은 오른쪽 정면 작업판으로 펼쳐지고, 프로젝트 하이어라키와 전체 모듈 공간은 아래 탐색대로 내려갑니다.


03
라이트 모드
라이트 · 코드와 AI 근거도 기울이지 않고 읽기
모듈을 펼치면 같은 오른쪽 작업판 안에서 코드·속성·AI 설계 요약을 읽습니다. 왼쪽 API 채팅과 프리뷰, 아래쪽 전체 프로젝트를 동시에 확인합니다.


04
다크 모드
다크 · 같은 프로젝트의 공간 탐색
밤색·금색 대신 짙은 잉크색 유리에 푸른 빛과 보랏빛 반사를 사용합니다. 라이트 모드와 같은 프로젝트·같은 배치 규칙을 유지합니다.


05
다크 모드
다크 · 구성과 속성을 정면에서 조작
오른쪽 작업판은 다크 모드에서도 완전히 정면입니다. 아래쪽 전체 모듈 탐색대가 출처와 다른 기능을 유지하고, 선택한 구성만 위로 펼쳐집니다.


06
다크 모드
다크 · 기존 CLI와 변경 검토
기존 Codex CLI의 MCP 조회와 변경안이 같은 화면에 연결됩니다. 오른쪽은 변경 전후와 영향 범위, 아래쪽은 전체 프로젝트 탐색 영역입니다.


이미지 생성 도구로 만든 설계 시안입니다. 화면 속 코드·모듈 수·AI 처리 상태는 가상 예시입니다. 실제 EXE는 수정하지 않았습니다.
위 배치 예시는 선택·모듈 확인·값 변경의 화면 동작만 보여줍니다. 전체 모듈의 3D 이동, 실제 코드 동기화와 AI 실행은 구현된 기능이 아닙니다.
