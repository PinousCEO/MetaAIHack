Depth AI · 주요 화면 설계 18장

생성 프롬프트 ↗

3·4번 스타일을 바탕으로 한 동작 설명 프리뷰 중심의 화면 흐름. 게임 상시 실행을 전제로 하지 않으며 웹·앱·게임을 함께 다룹니다.
각 이미지는 구현완료 화면이 아닌 설계 예시입니다. 클릭하면 확대되며 좌우 방향키로 순서대로 볼 수 있습니다.

01
시작·연결

프로젝트 홈

Depth AI 시작 화면에서 새 프로젝트를 만들거나 웹·앱·게임 기존 프로젝트를 고릅니다.

02
시작·연결

CLI·MCP 연결

기존 CLI를 유지하며 모듈 검색·조회·소스 접근을 연결합니다.

03
시작·연결

기존 프로젝트 분석

소스·UI·에셋을 읽고 구조와 AI 설명 기록을 만드는 과정을 보여줍니다.

04
탐색·선택

프로젝트 전체 공간

전체 프로젝트에서는 기능 구역을 접어 보고, 선택한 구역만 가까이 펼칩니다.

05
탐색·선택

화면·페이지·씬 목록

페이지·앱 화면·게임 씬을 같은 탐색 체계로 고르고 연결된 동작을 봅니다.

06
탐색·선택

웹 UI 요소 선택

웹 화면의 버튼을 고르면 해당 UI·처리 기능·데이터·에셋이 연결됩니다.

07
탐색·선택

앱 UI 요소 선택

앱 화면에서도 버튼을 통해 입력 검증·저장·알림 모듈을 불러옵니다.

08
탐색·선택

게임 씬 이동 설명

게임을 계속 실행하지 않고도 시작 버튼의 씬 이동 경로를 설명합니다.

09
탐색·선택

관련 모듈이 모이는 순간

선택한 결과의 관련 구현이 모여 하나의 기능 구성으로 펼쳐집니다.

10
동작·편집

동작을 단계별로 설명

클릭·검증·데이터 변경·화면 갱신을 한 단계씩 이해합니다.

11
동작·편집

모듈 수치 편집

구성 안에서 값을 바꾸고 설명 프리뷰의 변화와 수정 범위를 확인합니다.

12
동작·편집

코드와 AI 설계 기록

기능 모듈을 열어 실제 구현과 AI가 남긴 목적·근거를 함께 읽습니다.

13
AI 개발

CLI 작업과 모듈 변경

기존 CLI가 프로젝트 정보를 참고해 변경안을 만들면 관련 모듈에 표시합니다.

14
AI 개발

변경안 검토와 검증

소스·모듈·영향 범위를 검토하고 적용 및 검증 상태를 구별합니다.

15
분리·통합

기능을 재사용 단위로 분리

모인 구성에서 공유 의존성과 입출력을 확인하며 재사용 가능한 기능 경계를 검토합니다.

16
분리·통합

다른 프로젝트와 기능 통합

대상 프로젝트에 다른 프로젝트의 기능을 맞춰 연결하고 검증 전 상태를 표시합니다.

17
근거·검색

확인되지 않은 관계와 오류

모르는 관계를 숨기거나 사실처럼 꾸미지 않고 근거 상태를 구별합니다.

18
근거·검색

AI 기록 검색과 다시 찾기

AI와 사용자가 같은 목적·생성 이유·관계 기록으로 필요한 구현을 다시 찾습니다.

01→18 순서로 Depth AI의 사용 흐름을 봅니다. 웹·앱·게임은 동일한 모듈 탐색 체계를 사용하며, 아래 화면은 모두 같은 제품의 다른 상태입니다.
