기존 5번의 어두운 유리 공간과 모듈 배경을 기준으로 구성했습니다. 오른쪽은 프로젝트 전체, 앞으로 나온 묶음은 선택한 기능입니다.
다크: 차콜·세이지·브론즈 / 라이트: 상아색·돌색·세이지. 프리뷰·코드·입력은 정면, 모듈 몸체와 뒤쪽 공간은 사선입니다.

기준이 된 기존 5번 ↗
01
다크 · 선택과 이동

선택 전: 오른쪽 공간 전체가 실제 모듈

프리뷰는 왼쪽에 고정합니다. 오른쪽 뒤편에는 기능별로 모인 프로젝트 모듈이 깊이를 따라 놓입니다. 가까운 모듈에는 역할과 작은 내용이 보이고, 먼 모듈은 묶음으로 줄여 표시합니다.

02
다크 · 선택과 이동

선택 순간: 관련 모듈이 원래 자리에서 앞으로

쿠폰 버튼을 고르면 계산·상태·화면·검증 모듈이 각자의 위치에서 앞으로 모입니다. 원래 자리에는 희미한 기준점이 남아 전체 프로젝트와의 관계를 잃지 않습니다.

03
다크 · 선택과 이동

도착 후: 기능을 이루는 모듈과 값을 함께 편집

모인 모듈 안에서 역할·연결·속성을 읽고 바꿉니다. 할인율 20%를 25%로 바꾼 예시에서 합계는 $96에서 $90으로 바뀝니다. 공용 모듈은 복제하지 않고 같은 구현을 참조합니다.

04
AI 작업 · 같은 프로젝트

API 키 모드: 채팅도 같은 모듈과 코드로 작업

API 채팅은 질문만 받는 도움말이 아닙니다. 모듈 검색과 소스 확인, 변경안 작성, 검증 과정을 작업 화면 안에서 보여줍니다. 선택한 기능과 프리뷰도 계속 보입니다.

05
라이트 · 동일한 구조

라이트 모드: 상아색 공간 속 모듈 전체 보기

다크 모드와 구조는 같습니다. 상아색·연한 돌색·세이지로 공간을 밝히고, 기울어진 배경과 정면 프리뷰를 분리해 깊이와 조작성을 함께 유지합니다.

06
라이트 · 동일한 구조

라이트 모드: 모듈 조립과 API 채팅을 한 화면에

선택한 기능은 앞으로 나온 반투명 묶음이 됩니다. 채팅·프리뷰·값 입력·코드는 정면으로 두고, 모듈 몸체와 뒤쪽 공간에만 사선과 깊이를 줍니다.

07
AI 작업 · 같은 프로젝트

기존 CLI 모드: MCP 작업이 공간에 반영되는 모습

기존 Codex CLI를 그대로 사용합니다. MCP로 조회한 모듈과 변경 대상이 Depth AI 공간에서 강조되고, 결과는 같은 변경 검토 흐름으로 이어집니다.

08
AI 작업 · 같은 프로젝트

코드·근거·변경 검토, 그리고 연결 설정

모듈을 펼치면 실제 소스 위치, 검증 가능한 설계 요약, 영향 범위와 변경안을 봅니다. CLI/MCP와 API 키 연결 설정을 별도 창으로 제공하며, 키는 가려 표시합니다.

수천 개도 모두 펼치지 않습니다

기능별 묶음 → 가까운 개별 모듈 → 선택한 구성 순서로 자세해집니다. 멀리 있는 모듈은 묶음과 대표 내용으로 줄여 표시하고, 검색·계층 목록으로 바로 찾습니다.

앞으로 와도 같은 구현입니다

출처 위치를 희미한 기준점으로 남깁니다. 공용 모듈은 같은 ID를 참조하고, 어디서 사용하는지도 표시합니다. 시각적 모으기는 코드 복사나 프로젝트 통합 자체를 뜻하지 않습니다.

CLI와 API 채팅은 같은 도구를 씁니다

모듈 검색·소스 읽기·변경안·검증을 같은 프로젝트 문맥에 연결합니다. 선택한 모듈과 코드가 어떤 AI 작업에 쓰였는지 화면에서 확인하는 구성입니다.

이미지 생성 도구로 만든 설계 예시 8장입니다. 화면의 프로젝트·코드·모듈 수·처리 상태는 가상 예시이며, 구현되거나 검증된 결과가 아닙니다.
