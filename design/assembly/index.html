각 부품은 실제 코드에 연결된 기능 구역입니다. 부품을 펼쳐 모듈과 원본 구현을 확인합니다. 공통 데이터는 하나의 중심 구현으로 유지합니다.

분석기는 광학 스캐너, 변경 관리는 저장 장치, 공통 모델은 여러 참조가 모이는 결정 구조, 실행 화면은 디스플레이로 표현했습니다. 이러한 외형과 배치는 탐색을 위한 시각적 비유입니다.

6개 기능 구역·21개 제안 모듈·214개 실제 심볼·260개 분석 관계를 사용합니다. 이 시안은 실시간 실행 화면, CLI/MCP 이벤트 수신, 자동 코드 변경과 갱신을 연결하지 않았습니다.

전체 구성과 기능별 강조는 동작합니다. 수천 개 모듈의 배치·탐색 성능은 검증하지 않았습니다. 새로운 시각 구조를 평가하는 브라우저 프로토타입이며 Unity EXE는 변경하지 않았습니다.
