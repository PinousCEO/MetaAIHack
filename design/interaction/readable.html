기존 CLI를 그대로 사용합니다. 아래는 그 연결 과정을 설명하는 예제입니다.

1. 프로젝트 참고MCP: modules.search

기존 퍼즐과 지갑 모듈·코멘트를 찾습니다.

2. 코드 확인MCP: source.read

3. 코드 작성RewardService.cs

기존 지갑을 사용하는 보상 코드를 추가합니다.

4. 구조 갱신변경 분석 → 모듈·관계

새 보상 모듈, 생성 이유와 연결을 반영합니다.
